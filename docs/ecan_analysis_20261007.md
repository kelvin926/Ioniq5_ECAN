# ECAN 실차 기록 분석

2026-10-07에 수집한 CAN 기록과 함께 저장된 센서를 대조한 오프라인 분석이다.
현재 결과는 **97개 ID, 605개 필드 배치와 대안, 3,892개 해석 비트 위치**다.
조사한 전체 CAN은 138개 ID, 1,914,473프레임이며 캡처 구간 합계는 656.831초다.

> 2026-10-08 검증 갱신: 이 문서의 표는 10월 7일 스냅샷으로 그대로 둔다. 조향각 `#002` 부호,
> `ObjValid` 의미, `0x060.BRAKE_PRESSED` 해석 등 18개 필드는 틀린 것으로 판정했고, 41개 미해석
> ID의 CRC 구조와 미할당 비트 548개를 추가 해석했다. 현재 발행 정의와 검증 요약은
> [ECAN 전체 해석 필드 토픽](ecan_signals.md#2026-10-08-검증)을 따른다.

## 핵심 해석

| ID | 실제 비트 | 뜻 | 결과 |
| --- | --- | --- | --- |
| `0x0DA` | 64~79 | 차속 | `raw × 0.01 m/s`, GPS와 외부 레이더 연동 |
| `0x04A` | 64~79 | 요레이트 | `raw × 0.005 − 163.84 deg/s`, GPS 궤적과 연동 |
| `0x125` | 24~39 | 조향각 | 기록된 순방향 주행에서 `raw × +0.1 deg`의 좌회전 양수 근거 |
| `0x175` | 32~42 | 기준 종가속도 | `raw × 0.01 − 10.23 m/s²`, GPS 운동가속도 연동 |
| `0x1AA` | 48~55 | 보정 표시속도 후보 | `raw × 0.5 km/h`, 속도 의존 보정 패턴 |
| `0x4B4` | 18~19 | 내비 순환번호 후보 | 이전 `19:2` 배치 수정 |
| `0x4B8`, `0x4B9` | 45~46 | 내비 순환번호 후보 | FF 제외 시 0~3 순환, 표본 제한 |
| `0x4BE` | 59~60 | 내비 순환번호 후보 | 이전 `45:2` 배치 수정 |
| `0x4BF` | 56~57 | 내비 순환번호 후보 | FF 제외 시 0~3 순환 |

`0x1AA`의 경험 보정 모델은 `D ≈ v + min(0.12v, 2.5)`이며 D와 v의 단위는 km/h다.
이후 캡처의 GPS 비교 오차는 약 0.31 km/h, 양쪽 레이더 비교 오차는 약 0.28 km/h였다.
실제 계기판 화면과 OEM 보정식을 직접 확인하지 않아 표시속도 후보로 유지했다.

## 읽는 기준과 한계

- 비트 번호는 첫 바이트 B0의 최하위 비트 b0부터 계산한다. 실제 위치는 `8×B+b`다.
- 표의 값은 CAN payload에서 해석한다. 함께 기록된 센서의 위치나 객체값은 검증 참조다.
- 필드 수에는 폭/부호/단위 대안과 세부 비트 정의가 포함된다. 독립 물리량 605개를 뜻하지 않는다.
- 의미를 붙이지 못한 비트는 현재 표시 표에서 제외하고 원본 감사 기록에 보존했다.
- 마지막 bag은 검증된 색인 앞부분만 사용했다. 원본을 수정하거나 재색인하지 않았다.
- CAN 시각은 호스트 수신 시각이다. 영상은 큰 헤더 시계 차이를 확인해 bag 기록 시각으로 대조했다.
- 새 절대 GPS 좌표, 원시 레이더 객체목록, 모터 부하의 Nm/A 단위는 확정되지 않았다.
- 명령값, 송신 값, ECU 피드백, 물리 측정값을 구분한다. 이 연구는 런타임 DBC나 제어 검증을 대체하지 않는다.

## 분석 이력

같은 날짜에 여러 분석 단계가 진행됐다. 아래 문서와 JSON은 당시 관측과 가설의 기록이며,
현재 해석에는 위의 최신 필드 표와 센서 대조 결과를 먼저 사용한다.

| 단계 | 문서 | 보존한 근거 |
| --- | --- | --- |
| CAN 구조 및 초기 DBC 비교 | [구조](ecan_capture_structure_20261007.md), [원본 필드](ecan_fields_20261007.md) | `ecan-structure`, `ecan-fields` JSON |
| 전체 ID 수치 추론 | [추론 과정](ecan_inference_20261007.md), [138개 ID](ecan_inference_all_ids_20261007.md) | `ecan-deep-inference`, 초기 source audit JSON |
| 전체 비트 감사 | [감사 자료](evidence/2026-10-07/ecan-korean-bit-dictionary-20261007.json) | 17,920개 위치의 구조/통계, 식별번호 값 생략 |
| Exa 추가 검색 및 CAN 내부 추론 | [추가 추론](ecan_followup_inference_20261007.md) | Exa source audit, 후보 검증 및 이전 표시 receipt |
| 동시 기록 센서 대조 | [현재 검증](ecan_bag_reference_inference_20261007.md) | bag-reference inference 및 현재 receipt |

이전 단계의 `0x1AA raw×0.125 m/s`와 일부 내비 순환번호 배치는 현재 표에서 대체됐다.
원본 수치 ZIP과 중간 계산 캐시는 로컬 분석 자료이며 이 저장소 배포에 포함하지 않는다.

## 근거와 공개 범위

공개 DBC/code 비교는 문서에 적힌 커밋으로 고정했다. 런타임 핀과 연구 스냅샷은 별개다.
[DBC 저작권 및 허가 고지](evidence/2026-10-07/DBC_SOURCE_LICENSE.txt)를 함께 보존한다.
[날짜별 근거 목록](evidence/2026-10-07/README.md)에서 파일의 역할과 검증 범위를 확인할 수 있다.

저장소에는 한국어 문서, 조회용 HTML, 집계 JSON과 검증 근거를 포함한다.
원본 bag, 센서 원시 영상/점군, 장치 식별번호 값과 절대 GPS 좌표는 포함하지 않는다.
분석 코드와 중간 계산은 로컬 작업공간의 분석 캐시에 보존됐으며,
공개된 수치 근거만으로 원본 수신의 완전성이나 모든 물리 단위를 재검증할 수는 없다.
